# MedDocs Android releases

This public repository contains compiled Android packages for MedDocs. Source
code and application data remain in the private [MedDocs source repository](https://github.com/space-cadet/med-docs-v2).

Download the latest installable APK from the [Releases page](https://github.com/space-cadet/med-docs-releases/releases).

Release tags use the form `v<version>-build-<number>`. The APK filename includes
the same version and public build number. AAB files, when published, are for
Google Play distribution.
